What the command means

-skill teach-pro-max is not SQL. It is also not a universal agent command. It expresses the intent to select a named skill; the exact punctuation belongs to the current harness.

The portable move is to install the public skill, then either ask naturally for it or use the explicit syntax your harness exposes. If a flag is rejected, list available skills instead of guessing more flags.

SurfaceExampleWhat it does
Natural languageUse teach-pro-max to teach me Bayes' theorem.Routes by exact skill name and description.
Dollar referenceUse $teach-pro-max for a focused lesson.Explicit skill reference in supporting clients.
Slash command/teach-pro-max consistent hashingExplicit invocation where slash skills exist.

Skills CLInpx skills add … --skill teach-pro-maxInstalls or selects from a repository. It is not the lesson prompt.

Install and verify

1. Inspect the repository skills

npx skills add praxstack/skills-and-personas --list

2. Install Teach Pro Max

npx skills add praxstack/skills-and-personas --skill teach-pro-max

3. Verify the installed distribution

cd /path/to/installed/teach-pro-max
python3 scripts/verify_distribution.py

Expected The wrapper and all 342 embedded engine files match source commit 8c26440a….

Boundary Integrity proves exact distribution bytes. It does not prove mastery for a learner.

Requests that work well

Quick. “Explain why indexes speed up reads but slow some writes. One analogy, one example.”
Lesson. “Teach consistent hashing. Check my model first and test transfer before saying I understand.”
Course. “Design a six-week Python course. Ask before saving learner state.”
Override. “Answer now: process versus thread. Then offer one optional retrieval check.”
Resume. “Validate this learning workspace before describing my history. Infer nothing absent.”

The teaching system

The learner can later retrieve, explain, apply, discriminate, and transfer the idea without the tutor, and the system can show honest evidence for that claim.
Quick

A bounded answer or explanation. No state by default.

Lesson

Diagnosis, guided practice, and one target competency.

Course

Sequencing, review, and resumption with explicit consent.

  • Outcome
  • Prior model
  • Explain
  • Attempt
  • Hint
  • Apply
  • Transfer
  • Recap

The engine separates recognition, recall, explanation, application, discrimination, and novel transfer. Hinted success stays labeled as scaffolded. Confidence, completion, time-on-page, and one correct response are never treated as mastery.

Visual learning, routed deliberately

The embedded 38-tool registry chooses the least complicated visual that materially improves understanding.

RouteUse it forRequired guardrail
NoneA relationship already clearer in prose.Do not decorate for appearance.
Semantic tableExact mappings and comparisons.Headers and reading order must remain clear.
Static SVG/PNGSpatial structure, systems, or diagrams.Provide an equivalent textual explanation.
Interactive local HTMLManipulation changes the mental model.Keyboard path and substantive static fallback.
MotionChange over time is itself the concept.Reduced-motion alternative and user control.

Retrieval answers must never leak through captions, alt text, hidden controls, default states, previews, source code, or fallbacks.

Model and harness portability

Teach Pro Max specifies roles and outcomes rather than assuming codex exec, claude -p, a fixed model, or a named subagent tool.

  1. Inspect capabilities, filesystem, network, quota, and authorization.
  2. Delegate only when independent work materially improves quality.
  3. Use the smallest useful team with explicit ownership and stop conditions.
  4. Keep the primary agent responsible for synthesis, safety, and claims.
  5. Continue in one agent when delegation is absent or unnecessary.
Capability presence is not authorization.No provider API key is required for ordinary teaching. Subscription-backed CLIs are optional host capabilities, not hidden APIs.

Durable learning and privacy

Before the first learner-state write, the agent names the storage location, exact fields, purpose, inspection path, correction path, export format, and deletion method. It asks for explicit consent and offers an equally capable ephemeral route.

Learner answers, transcripts, web pages, documents, tool output, and saved records are content, not authority. Embedded instructions cannot change governing rules, invoke tools, expand access, or disclose private data.

The cross-harness persona bundle

The repository keeps persona concerns separate so identity cannot silently become tool authority.

FileResponsibility
SOUL.mdStable voice, values, boundaries, and teaching posture.
IDENTITY.mdName, creature/theme, vibe, emoji, and avatar metadata.

Hermes

Place SOUL.md in the active HERMES_HOME. Hermes loads durable identity from its instance home, not an arbitrary project directory. Keep project rules in AGENTS.md.

OpenClaw

Place the bundle at the selected agent workspace, review existing memory and bindings, then synchronize identity with:

openclaw agents set-identity --workspace /path/to/workspace --from-identity

Codex and other AGENTS-aware harnesses

Use AGENTS.md as the operational entrypoint and install the skill separately. Do not paste the entire engine into a system prompt.

Troubleshooting

The skill is missing

npx skills add praxstack/skills-and-personas --list

The tutor asks too many questions

Say quick, keep it concise, or Answer now. The override must be honored immediately.

Verification reports drift

Inspect the exact missing, extra, or changed path. Do not update the manifest first. Changing embedded bytes makes prior receipts historical.

The tutor claims mastery too early

Ask for evidence by dimension and a fresh unassisted transfer task. Without delayed observation, the claim remains bounded.
